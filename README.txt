LOUGHTON OPERATIONS DASHBOARD V13.1 - LARGE TEXT

Self-contained release: CSS and JavaScript are embedded in index.html.

Changes:
- Larger clock, date and header text
- Larger card headings and update times
- Larger weather details
- Larger TfL and system status rows
- Larger BBC headlines, showing three rather than four
- Larger Live Brief
- Existing live-feed refresh, retry and cache logic retained

Install:
1. Create a new empty folder named v13-1.
2. Extract index.html and README.txt.
3. Test index.html and press Ctrl+F5.
4. Replace index.html in the GitHub repository.
5. Wait for GitHub Pages deployment, then reload Fully Kiosk.

Refresh cycles:
- Clock/date/countdown: 1 second
- TfL: 2 minutes
- BBC News: 10 minutes
- Weather: 15 minutes
